# AI 可引用性评分标准

## 核心原理

AI 搜索引擎（ChatGPT/Perplexity/Claude）在回答用户问题时，会从网页中提取「可引用段落」。
研究发现（Princeton/Georgia Tech，2024），GEO 优化的内容在 AI 生成回答中的引用率高出 30-115%。

**AI 倾向引用的段落特征：**
- 长度 134-167 字，自成一体
- 首句直接给出答案（答案前置）
- 包含具体数据、日期、命名实体
- 无需上下文即可理解

---

## 评分维度（总分100）

### 1. 答案块质量（30分）

| 分数 | 标准 |
|------|------|
| 90-100 | 每个主要章节首句直接回答，使用「X是...」「X指...」结构 |
| 70-89 | 大多数章节有明确答案开头，偶有模糊 |
| 50-69 | 部分章节有答案结构，但很多把答案埋在段落中间 |
| 30-49 | 答案普遍埋在长段落里，没有定义句式 |
| 0-29 | 完全没有可提取的答案块，纯叙事/口语化 |

**高可引用示例：**
```
内容分发网络（CDN）是将网络内容缓存并从距用户最近的节点提供服务的分布式服务器系统。
CDN 平均可将网页加载延迟降低 50-70%。截至2025年，全球最大的三家 CDN 提供商分别是
Cloudflare（服务约20%的网站）、Amazon CloudFront 和 Akakami Technologies。
```
✅ 字数：66字 | 自成体：是 | 数据点：3个 | 定义结构：是

**低可引用示例：**
```
如果你想知道为什么有些网站加载更快，答案可能会让你惊讶。这个技术已经存在很久了，
改变了我们对网络性能的看法。让我来解释一下它是如何工作的……
```
❌ 字数：55字 | 自成体：否 | 数据点：0 | 定义结构：否

---

### 2. 段落自包含度（25分）

每个段落能否脱离上下文独立理解。

| 分数 | 标准 |
|------|------|
| 90-100 | 80%+ 段落明确点名主题，不依赖代词指代前文 |
| 70-89 | 60-79% 段落自包含 |
| 50-69 | 40-59% 自包含，代词与明确主题混用 |
| 0-49 | 大量「它」「这个」「前者」等代词，必须结合上下文 |

---

### 3. 事实密度（20分）

| 分数 | 标准 |
|------|------|
| 90-100 | 每100字含3+个可验证事实（数字/日期/专有名词） |
| 70-89 | 每100字含2-3个事实 |
| 50-69 | 每100字含1-2个事实 |
| 0-49 | 几乎无具体数据，全是泛泛陈述 |

---

### 4. 结构信号（15分）

- H2/H3 标题包含关键词（而非「背景」「前言」）
- 使用有序/无序列表，方便 AI 提取
- 含 FAQ 或 Q&A 结构
- 有明确的日期和作者署名

---

### 5. 权威信号（10分）

- 引用外部权威来源（学术/媒体/行业报告）
- 有具体的作者信息（姓名+头衔）
- 有「最后更新时间」
- 包含原创研究或数据

---

## 优化建议

**立竿见影（1周内）：**
1. 每个 H2 章节的第一句改成定义句「X是...」
2. 把泛泛陈述改成有数据支撑的句子
3. 用代词「它」「这个」的地方换成具体名称

**中期（1个月）：**
1. 在关键页面添加 FAQ 模块
2. 补充作者署名和文章更新时间
3. 每篇文章至少引用2-3个外部权威来源

**战略（3个月）：**
1. 建立原创数据页面（调研/报告/统计）
2. 在 Wikipedia、Reddit、LinkedIn 建立品牌提及
3. 部署完整的 Schema 结构化数据
